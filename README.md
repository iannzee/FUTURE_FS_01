# Ziyan Patel Portfolio

A clean and professional personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive design for desktop and mobile
- Sections for About, Skills, Projects, Resume, and Contact
- Smooth scrolling and reveal animations
- Contact form with simple client-side feedback
- SEO-friendly meta tags

## Project Files
- `index.html` — main structure of the website
- `styles.css` — styling and layout
- `script.js` — interactivity and animations

## How to Run
1. Open `index.html` directly in your browser, or
2. Start a local server from this folder:
   ```bash
   python -m http.server 8000
   ```
3. Visit:
   ```text
   http://localhost:8000
   ```
